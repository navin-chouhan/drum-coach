## Step 1: choose the renderer (report before building on it)
`@shopify/react-native-skia` is the plan's candidate. Check it against the rules for the version matching Expo SDK
58.0.17's `bundledNativeModules.json`: age, major ≥ 1, **install scripts / binaries downloaded at install or pod
install** (`.npmrc` has `ignore-scripts=true`), and its transitive deps. If it fails, choose the best rules-compliant
option (Reanimated + plain views / `react-native-svg` if it passes / a small native view) and explain. **Don't add any
dependency yourself**: write the exact package@version you need in your report; the orchestrator adds it. Build part 1
on what's installed (Reanimated 4 + RN views + gesture-handler), behind a small renderer interface so swapping to Skia
later touches one file.

## Step 2: components (`apps/mobile/src/play/**`)
- `NoteHighway`: props `chart`, `bpm`, `zero` (heard beat 0, Clock ms), `now()` (the Clock), `latencyMs`, hit results
  stream; scrolls on the UI thread (Reanimated frame callback reading a shared clock value; no React re-render per
  frame); lanes per pad in the web's order and colours; judged hits light up.
- `KitView`: the kit drawn like the web's, pads flash on hits (shared values, no React state per hit).
- `TouchPads`: multi-touch pads laid out like the real kit; each touch → `emitPad(pad, velocity)` on an injected hit
  bus and → an injected `playNow(sound)` callback (A4's AudioPort); velocity from touch force/size where available,
  else fixed. ≥ 44 pt targets.
- A dev screen `apps/mobile/app/dev/play.tsx` showing all three driven by a fixture replay (core-agnostic: inject a
  fake chart + a timer for now) so the owner can see them on the iPad.
- Pure geometry (lane layout, time→y, hit judgement colours) in plain TS with Vitest tests.
